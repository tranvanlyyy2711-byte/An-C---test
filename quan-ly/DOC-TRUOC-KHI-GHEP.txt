DÀNH CHO BẠN GHÉP CODE:
1. Chép các thư mục/file trong gói vào thư mục gốc dự án, giữ đúng cấu trúc.
   KHÔNG tạo đường dẫn /quan-ly/Tin-Dang-Da-Sua/... trên website.
2. Ở thư mục gốc dự án, chạy:
   git apply --check --ignore-space-change --ignore-whitespace patches/ket-noi-tin-dang.patch
   Chỉ khi lệnh trên thành công mới chạy:
   git apply --ignore-space-change --ignore-whitespace patches/ket-noi-tin-dang.patch
   Bản vá dựa trên ZIP GitHub An-C---test-main(1).zip người dùng gửi ngày 26/10.
   Nếu báo lỗi do file đã sửa/đã ghép, dừng và đối chiếu từng hunk; không ép ghi đè toàn file.
3. Vercel cần áp dụng migration supabase/migrations/0004_tin_dang.sql vào Supabase,
   kiểm tra SUPABASE_URL / SUPABASE_ANON_KEY / SUPABASE_SERVICE_ROLE_KEY trên Vercel,
   rồi deploy lại. Không đưa service-role key vào code frontend hoặc chat.
   Xem HUONG-DAN-TIN-DANG-VERCEL.md.
